## 1. 3ゾーン爆発数理モデル（Three-Zone Explosion Model）

爆心地 $(x_0, y_0)$ からのユークリッド距離 $r$ に基づき、影響を 3 つのゾーンに分割して評価します。

```text
               r = R_blast (最大衝撃波半径)
             /
            /     r = R_crush (破砕半径)
           /    /
          /    /   r = R_vapor (蒸発半径)
         /    /   /
       ┌──────────────────────┐
       │ ゾーン 3: 衝撃波     │  -> エンティティのノックバック & 構造崩壊トリガー
       │ ┌──────────────────┐ │
       │ │ ゾーン 2: 破砕   │ │  -> ブロックを粉砕・自由落下粒子化して外向きに射出
       │ │ ┌──────────────┐ │ │
       │ │ │ ゾーン 1: 蒸発│ │ │  -> ブロック完全消滅 (AIR 置換)
       │ │ │     (★) 爆心 │ │ │
```

### 数理モデル
1. **ゾーン 1: 蒸発（Vaporization Zone: $0 \le r < R_{\text{vapor}}$）**:
   超高熱と圧力により、岩盤も土も完全に気化・消滅し、クレーターの中心空洞（AIR）を形成。
   $$ R_{\text{vapor}} = 0.4 \times R_{\text{total}} $$
2. **ゾーン 2: 破砕（Crush Zone: $R_{\text{vapor}} \le r < R_{\text{crush}}$）**:
   ブロックは粉砕されて構造強度を失い、`FLAG_FALLING` が付与される。
   同時に、爆心地からの外向きベクトル $\vec{v}_{\text{blast}} = \frac{\vec{r}}{r} \times P(r)$ に従って空中に吹き飛ばされ、水しぶき・破片パーティクルとして散乱する。
3. **ゾーン 3: 衝撃波（Shockwave Zone: $R_{\text{crush}} \le r \le R_{\text{total}}$）**:
   地形自体は直接破壊されないが、周囲の 4x4 ブロックに構造崩壊（自立限界チェック）の波及を促し、プレイヤーや敵に激しいノックバックと爆風ダメージを与える。

## 2. 圧力波減衰とノックバック計算式

爆風の威力 $P(r)$ は距離の 2 乗に反比例して減衰します。

$$ P(r) = P_0 \times \left(1 - \frac{r}{R_{\text{total}}}\right)^2 $$

* エンティティに加わるノックバック速度ベクトル:
  $$ \vec{v}_{\text{knockback}} = \frac{\vec{p}_{\text{entity}} - \vec{p}_{\text{bomb}}}{\|\vec{p}_{\text{entity}} - \vec{p}_{\text{bomb}}\|} \times P(r) \times \frac{1}{\text{Mass}_{\text{entity}}} $$
これにより、爆弾の直近にいる敵は壁に叩きつけられ、遠方の敵は軽くよろめくリアルな物理フィードバックが得られます。
