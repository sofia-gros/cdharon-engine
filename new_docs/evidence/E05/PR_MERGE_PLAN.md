**#4〜#10を基礎実装として維持し、#14〜#22とその後のE05修正を、最後に1本の集約PRへまとめる。**

E05のQ04全受け入れ条件と独立レビュー、CIが通過するまでは旧PRをcloseしない。集約PRの受け入れ完了後、置換元PRの説明文へ集約先を残して重複PRを閉じる。元ブランチやコミットは削除しない。

**#4 → #5 → #6 → #7 → #8 → #9 → #10 → #（集約PR番号）**
