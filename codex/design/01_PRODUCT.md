# 製品構想と範囲

共通仕様は[02_CONTRACTS.md](02_CONTRACTS.md)。工程は[09_ROADMAP.md](09_ROADMAP.md)。

## 製品の定義

Charon Engine 1.0は、破壊可能な2Dセル世界を作るための**Rustライブラリ、実行可能なサンドボックス、機能を組み合わせたサンプルゲーム、開発ドキュメント**を提供する製品です。完成した長編ゲームや汎用3Dエディタの制作とは分けて進めます。

核となる体験は「掘る → 地形が崩れる → 水や砂が移動する → 移動・採集・戦闘の条件が変わる」です。物理の見栄えと操作の安定性を両立し、ゲーム作者が物質・反応・アイテムを定義できるようにします。

製品版までの実装では、本設計の各ゲートを満たしてから次工程へ進みます。商用販売の価格・ストア・ライセンスは製品完成度とは別の意思決定で、現段階では未決定です。

## 1.0の範囲

| 領域 | 必須成果 |
| --- | --- |
| 世界 | 有限サイズのチャンク世界、段階生成、既定ONの画面外読み込み、遠隔保持API、編集の永続化 |
| セル物理 | 固体・粉体・液体・気体、局所的な崩落、熱・相変化・定義済み反応 |
| アクション | 移動、ジャンプ、水中移動、段差越え、高速移動の衝突判定 |
| 相互作用 | 採掘、配置、近接攻撃、投射物、爆発、組合せ可能な魔法効果 |
| コンテンツ | バイオーム、洞窟、鉱脈、構造物、歩行・飛行敵、1つのボス例 |
| ゲーム基盤 | インベントリ、クラフト、HP等のUI、入力再設定、音響 |
| 信頼性 | 保存・復元、リプレイによる再現、上限検証、障害診断 |
| 作者向け | TOML/PNGによる重さ・可燃性等の物性定義、型付き独自属性のアタッチ、Rust API、サンプル、移行説明 |

サンプルは、小さな世界で採掘・クラフト・探索・戦闘・保存が一巡できれば合格です。素材数やゲームの長さを増やして基盤完成を遅らせません。

## 1.0で約束しないこと

- マルチプレイ、ネットワーク・ロールバック、異なる版間のリプレイ互換
- 無限世界、非表示領域を含む全世界の常時シミュレーション
- 実在流体と一致する圧力・非圧縮性、SI単位系での化学・質量保存
- 回転する破壊可能剛体、大規模な弾性体・有限要素法による構造解析
- GPUでの正規物理、スクリプト実行環境、C ABI、他言語SDK
- コンソール、携帯機、モバイル、Web、全CPUでの無条件ビット一致

これらは別の研究・製品工程です。拡張余地は残しますが、未実装のバックエンドに合わせて基盤を複雑化しません。

## 対象環境と目標

最初の開発・出荷検証はWindows 11 x86-64です。Linux/macOSはCI・実機確認を追加できる段階で対応候補とします。対応OS、GPUドライバ、Rust toolchainは出荷時に実測した組合せを一覧化します。

標準論理解像度は640×360、描画目標は60 FPS、物理は60 tick/sです。120/144Hz表示でも物理速度は変わりません。性能条件は[検証設計](07_VALIDATION.md)で固定します。

画面・キー設定、音量、点滅・画面揺れの軽減、UI倍率を提供します。色だけで重要状態を伝えず、データエラーと保存失敗は操作可能なメッセージを表示します。

## 成功の基準

新しい物質を登録するためにコア物理へ名前別分岐を足す必要がないこと、セーブから同じtick状態を復元できること、削った地形がプレイヤーを不意に壁抜けさせないことを優先します。CPU使用率やFPSの単独値だけで品質を判定しません。

定常物理更新では、事前確保した容量内で追加ヒープ確保を行わないことを目標とします。ロード・生成・保存・起動まで「ゼロ確保」と称しません。装飾が上限に達しても、物質・アイテム・プレイヤーの状態を黙って捨てません。
